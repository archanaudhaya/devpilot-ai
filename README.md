# DevPilot AI

## Agentic AI Software Engineering Assistant

DevPilot AI is an AI-powered software engineering assistant that analyzes
GitHub repositories, understands project structure, creates implementation
plans, assists with code changes, generates and runs tests, and supports
human-approved pull requests.

## Technologies

- React
- TypeScript
- Java
- Spring Boot
- Spring AI
- PostgreSQL
- GitHub API
- Docker
